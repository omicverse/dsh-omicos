# 0008 — AnnData exploration uses explicit bounded read projections

Exploring an existing AnnData must not silently normalize, log-transform, filter observations or recompute an embedding. The explorer therefore generates a reviewable Python cell against the existing project kernel. Both HTTP and Agent paths require the existing approval boundary, and stable operation IDs refer to the actual scientific execution receipt. GUI plots use the generation of the approved object inspection; a lost kernel rejects the plot without starting a replacement namespace.

Metadata inspection exposes bounded obs schema and embedding shapes without converting expression matrices to dense arrays. The plot contract names an existing embedding and two zero-based dimensions, or an explicit obs/feature distribution. Numeric metadata is continuous; categorical/bool metadata uses discrete labels. Expression coloring explicitly chooses X, one layer or raw.X and requires unambiguous feature identifiers. Missing layers/embeddings/features, duplicate requested metadata and duplicate feature names fail visibly rather than guessing. No source is presumed to be raw counts or normalized data.

Uniform, seed-fixed observation sampling is without replacement, capped at 10000 rows. Embedding matrices must be aligned and have at most 1024 columns; only the requested columns are extracted. Feature coloring materializes one selected expression column. Sparse/backed sparse reads are split into 128-row chunks before conversion of the selected column; no full expression matrix is densified. Supported CPU array/dataframe/HDF5/sparse backends are explicit; arbitrary lazy/device backends require separate approved code. Public backed-sparse types use the current AnnData API with its older public experimental fallback.

Masked array entries remain missing rather than exposing masked underlying values. Non-finite coordinates are excluded and counted; missing/non-finite numeric colors are grey. Numeric distributions use the finite sampled values; categorical distributions include a missing-value bar. More than 20 categories in the preview sample reject before plotting, and identifiers/labels have explicit length limits. Labels/counts describe the sampled preview, not full-dataset proportions, validated clusters or independent biological replicates. The UI exposes the selection, source, dimensions, seed, limit and generated code before approval.

PNG/PDF/SVG artifacts use the existing execution capture and hash-serving boundary and can be curated in Figure Studio. A structured audit records the normalized settings, original/selected/rendered observation counts, missing-coordinate/color counts and a SHA-256 of the selected indices, observation-name identity, visible coordinates and color values/categories. Observation names and full expression arrays are not emitted into the audit. This is a preview-subset fingerprint, not a claim of full-input I/O coverage, transform history or scientific validity.

The Python worker now captures partial figures against the actual failed execution and always closes owned figures before handling another cell; explicit cancellation skips expensive capture. Previously a failed plotting cell could leave an open figure to be collected under a later successful receipt. Error text/failed state and partial artifacts remain together, with no automatic approval or rerun.

The workbench uses the same Python project namespace even when the separate R pane is selected. Task status is read from a targeted owner-authenticated receipt endpoint, without starting another interpreter or transferring the full execution history on every poll. Hidden views pause polling and window closure does not cancel approved background work. Unknown submission retries retain the same operation ID while options are unchanged. Existing receipts/Figure Studio preserve results across a page reload; the explorer's current editing form is window-local.

Checks cover deterministic sampling, sparse X/layers/raw/obs/obsm preservation, read-only backed-file hashes, multiple sparse read chunks, nullable metadata, category/missing-embedding/ambiguous-input limits, safe quoted keys, generation fencing, approval and receipt auth, failed-figure attribution and actual browser plotting with artifact/sample evidence. Compatibility and platform evidence is recorded in IMPLEMENTATION_STATUS.md rather than inferred from one green environment.
