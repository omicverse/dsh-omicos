# Figure Studio publication assemblies

Goal: editable multi-panel scientific figures with retained source identities, human review and portable export. Reuse the existing original-figure registry, never regenerate scientific plots or copy private Core source.

Architecture: independent project SQLite immutable assembly revisions/current pointers/operation receipts. A bounded layout pins exact existing Figure Studio revisions, not arbitrary file paths or model-supplied image bytes. Host resolves real PNG headers, bytes/hash and source metadata. Preserve each original PNG without cropping, recoloring or resampling; fit it proportionally inside its panel. Labels are escaped literal text. Layout changes/recapture reset review. Drafts can describe failed/withdrawn source results, but fresh assembly approval requires unchanged currently approved source figure versions and verified artifact bytes. Prior assessments remain historical.

Initial implementation: 1–16 PNG panels, bounded coordinates/page dimensions, total source-byte/pixel limits, source version snapshots, immutable history/CAS/retry, integrity checks, human-only review, standalone SVG containing exact PNGs and provenance metadata, workbench source picker/layout editing/preview/history/export and read/propose Agent tools. SVG output contains no external image/font URLs, script or foreignObject and is served as an attachment. Current source drift is recorded separately from historical review in export; missing/changed original bytes reject the image export. No implicit claim that human approval establishes scientific validity.

Follow-on publication work: font-aware PDF output, JPEG/vector input handling without unsafe active content or hidden conversion, richer layout controls/templates, journals' physical-size/color/export conventions and publication data bundles. The SVG phase is a concrete step toward that full workflow, not a claim that all publication formats are complete. Underlying single Figure Studio PNG/PDF/SVG/JPEG source export remains available.

Acceptance: real Python-produced PNG sources, exact embedded byte identity, proportional geometry, XML injection containment, data/byte limits, stale source review rejection, historical source snapshots, state/revision/retry/restart, owner/CSRF isolation, browser preview/export/reload and full regression checks. No second model loop, scientific execution during composition/export or automatic publication/upload.
